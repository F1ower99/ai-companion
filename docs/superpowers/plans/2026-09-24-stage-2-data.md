# 阶段 2：本地数据与今日任务界面实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [x]) syntax for tracking.

**目标：** 为目标、任务和记忆建立本地 SQLite 存储，按完整路线图创建七张业务表，并交付可实际使用的“今日任务”界面。

**架构：** 不可变领域模型和校验放在不依赖 UI 的 domain 包。application 服务通过仓储 Protocol 操作数据；SQLite 负责迁移、持久化和事务。桌面任务界面只调用 TaskService；即使本地存储不可用，桌宠和聊天外壳仍可启动。

**技术栈：** Python 3.10+、标准库 sqlite3、PySide6 Essentials 6.11.2、pytest、pytest-qt。

**规格：** docs/superpowers/specs/2026-09-24-stage-2-data-design.md

## 全局约束

- Python 版本为 3.10 或更高；PySide6-Essentials 固定为 6.11.2；SQLite 不增加运行时依赖。
- 默认数据库路径为当前用户 LOCALAPPDATA/AICompanion/companion.sqlite3；测试使用临时文件。
- 每个连接启用外键；写操作使用事务和参数化 SQL。
- 版本 1 创建 goals、tasks、memories、conversations、messages、settings、reminders 和 schema_migrations。
- 已发布迁移不可修改；版本 1 之后的结构变化必须新增编号迁移。
- domain 和 application 不导入 Qt、sqlite3 或厂商 SDK。
- 本阶段只建立对话、设置、提醒的数据库结构，不实现活动监测、聊天功能、提醒调度、模型凭据、语音、云同步或向量检索。
- provider secret 不得写入 settings、SQLite、日志、测试或源代码。

## 重点评审风险

- 空白名称、无效枚举、负时长/进度、零目标、无时区或逆序硬时间必须在领域/服务边界报错；在任务 1 和任务 5 覆盖。
- 任务引用不存在的目标，或目标仍有关联任务时尝试删除，必须失败且不留下部分写入；在任务 2、4 覆盖。
- 迁移中途失败时，DDL 与版本记录都必须回滚；在任务 2 覆盖。
- 记忆查询默认排除过期项，遵循筛选和正数上限，删除只影响指定 id；在任务 4 覆盖。
- 本地数据目录无法打开时，桌宠和聊天外壳仍可运行，并清楚显示任务存储不可用；在任务 7 覆盖。

        CREATE_SCHEMA_MIGRATIONS_TABLE = (
            "CREATE TABLE IF NOT EXISTS schema_migrations "
            "(version INTEGER PRIMARY KEY, applied_at TEXT NOT NULL)"
        )

        VERSION_ONE_STATEMENTS = (
            CREATE_GOALS, CREATE_TASKS, CREATE_MEMORIES, CREATE_CONVERSATIONS,
            CREATE_MESSAGES, CREATE_SETTINGS, CREATE_REMINDERS,
            CREATE_TASK_INDEXES, CREATE_MEMORY_INDEXES,
        )
        MIGRATIONS = ((1, VERSION_ONE_STATEMENTS),)

        def read_schema_version(connection):
            return connection.execute(
                "SELECT COALESCE(MAX(version), 0) FROM schema_migrations"
            ).fetchone()[0]

        def utc_timestamp():
            return datetime.now(timezone.utc).isoformat()

        def apply_migrations(connection):
            connection.execute("BEGIN IMMEDIATE")
            try:
                connection.execute(CREATE_SCHEMA_MIGRATIONS_TABLE)
                current = read_schema_version(connection)
                for version, statements in MIGRATIONS:
                    if version > current:
                        for statement in statements:
                            connection.execute(statement)
                        connection.execute(
                            "INSERT INTO schema_migrations(version, applied_at) VALUES (?, ?)",
                            (version, datetime.now(timezone.utc).isoformat(),),
                        )
                connection.commit()
            except BaseException:
                connection.rollback()
                raise

- [x] **步骤 3：实现 connection context manager。** 每个仓储操作通过此上下文取得独立句柄；正常退出提交，异常退出回滚，finally 关闭句柄。SQLite 打开或迁移失败转换为 StorageError，业务异常原样传播，错误文字不带本地路径和数据值。

        @contextmanager
        def connection(self):
            try:
                self.path.parent.mkdir(parents=True, exist_ok=True)
                handle = sqlite3.connect(self.path, timeout=5.0)
            except (OSError, sqlite3.Error) as error:
                raise StorageError("Local database unavailable.") from error
            try:
                try:
                    handle.row_factory = sqlite3.Row
                    handle.execute("PRAGMA foreign_keys = ON")
                    handle.execute("PRAGMA busy_timeout = 5000")
                    apply_migrations(handle)
                except sqlite3.Error as error:
                    handle.rollback()
                    raise StorageError("Local database unavailable.") from error
                try:
                    yield handle
                    handle.commit()
                except sqlite3.Error as error:
                    handle.rollback()
                    raise StorageError("Local database unavailable.") from error
                except BaseException:
                    handle.rollback()
                    raise
            finally:
                handle.close()

            if task is None:
