# 首次桌面体验清单

自动测试、编译与隔离启动已经分别记录；以下项目需要真实桌面和设备体验，不能用测试数量代替。按顺序检查即可，不必一次配置所有功能。

1. **桌宠与退出。** 从最新完整 `AICompanion.dist` 目录启动 `app.exe`，不要单独移动 exe。拖动桌宠、点击打开聊天，再从托盘退出。确认没有额外控制台窗口，也没有退出后仍留在桌面的窗口。当前测试未替你完成这些桌面操作。
2. **任务与主动提醒。** 建立一个真实的近期任务，填写优先级、预计耗时和合理截止时间。先查看提醒设置及安静时段，再按需要启用提醒和最小活动感知。活动感知默认关闭；它只知道最近有无输入，不知道你是否正在写代码。当前没有前台应用名称或应用使用时长采集。
3. **语音草稿回复提醒。** 在已经显式配置本地识别模型的启动方式下，按住说话、松开，检查聊天草稿；草稿不会自动发送。打开当前提醒的“回复提醒…”面板，点击“填入聊天草稿”，预览，再确认。可试“再给我半小时”，但延期仍受剩余计划、硬截止和当天延期次数限制。到期会重新评估，不保证机械地再次弹窗。聊天草稿保持不变，取消面板不执行动作。
4. **耳机与音色。** 确认当前输出是耳机，再显式点击朗读。测试自然结束、主动停止、开始录音前停止朗读。Qwen 女声目前是显式选择的实验路线，短句合成可能需要数十秒；自然度还没有得到你的认可。不要把旧 Kokoro 的试听结果当成新音色已通过。
5. **隐私控制。** 暂停语音、关闭活动感知和主动提醒；确认不会继续采集。查看一条测试记忆并删除，清除测试对话；清除操作会先停止语音，停止失败时保留数据。真实 provider 测试只在你主动配置凭据并选好测试内容后进行。

现有 base 模型在中文公开短样例仍有识别错误；较大的 small 候选仅在该短样例经明确的繁简、数字和标点归一化后匹配，尚不能代表整体准确率。真实麦克风尚未验收。对话中的普通句子不会自动变成任务操作；免手动的语音指令路由、前台应用监测和自动长期记忆仍属于后续工作。
